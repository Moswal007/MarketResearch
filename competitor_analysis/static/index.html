Showing sample data — USE_MOCK_DATA=true is set in .env.
Google ratings come from the official Places API; Facebook pages (picture, category, summary, followers) come from Meta's Graph API when META_ACCESS_TOKEN is set, otherwise from Google Custom Search when it's configured. Instagram, Facebook, and Amazon are read from their public pages, which they restrict for logged-out automated requests, so results can be partial. Instagram has no public rating system at all (followers are shown there instead). Website/# products/price range come from a best-effort read of each company's own site (Shopify stores are reliable; most others are a rough estimate) — a dash means no website was found or it couldn't be read. Every rating is each listing's current total, not a year-by-year history — none of these platforms publish that.
